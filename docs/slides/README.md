# 卒業論文発表スライド

相関付きランダムウォークモデルを用いた時系列解析（7分・16:9・日本語）の
発表用 beamer スライドです。

- `presentation.tex` … スライド本体（各フレームに発表者ノート `\note{}` 付き）
- `figures/` … スライドで使用する図（本文 `docs/thesis/` からコピー）

## 構成（本編11枚＋付録1枚）

1. 表紙
2. 研究の背景と目的
3. 相関付きランダムウォーク：定義と行列による定式化（コイン行列・P/Q 分解・時間発展）
4. 確率分布で見る通常のランダムウォークとの違い（n=100 の分布と標準正規の比較）
5. 相関付きRWによる時系列予測：評価関数と当てはめ
6. 金価格データの離散化：平均練行足（変換前・変換後の比較グラフ）
7. 実験：金価格 XAUUSD への適用（全期間参照）＋ MAE の定義式
8. 改良：参照期間 W の導入（改良後の評価関数＋W スイープのグラフ）
9. モデルの限界：局面転換への追従の遅れ
10. まとめと今後の課題
11. 結び（ご清聴ありがとうございました）
12. （付録）相関付きRWの行列計算（n=1,2 の Ψ をベクトル×行列で明示）

理論パート（3〜5）は、相関付きRW（定義・行列定式化）→ 通常RWとの分布の違い
→ 予測モデルの順です。発表時間を7分に収めるため、次の2点を本編から外しています。

- 通常のランダムウォークの定義スライド（二項分布・n=1〜3 の表）は省略し、
  通常RWとの違いは4枚目の分布の比較グラフ1枚で見せる
- 相関付きRWの行列計算（n=1,2）は付録（12枚目）へ回し、質疑で必要になった
  ときだけ表示する（`\appendix` 以降にあるので本編の通しでは出てこない）

発表者ノートの時間配分は本編で合計約7分です。

## コンパイル方法（日本語 upLaTeX + dvipdfmx）

本文 `docs/thesis/main.tex` と同じ pLaTeX 系のワークフローです。
ファイルは UTF-8 で保存してください。

```sh
cd docs/slides
uplatex  presentation.tex     # 1回目
uplatex  presentation.tex     # 総ページ数・相互参照の確定のため2回目
dvipdfmx presentation.dvi     # presentation.pdf を生成
```

`platex` でもコンパイルできます。`latexmk` を使う場合は次の `.latexmkrc` を置くと
`latexmk presentation.tex` の一発で PDF まで生成できます。

```perl
$latex    = 'uplatex -synctex=1 -halt-on-error -interaction=nonstopmode %O %S';
$dvipdf   = 'dvipdfmx %O -o %D %S';
$pdf_mode = 3;   # dvi -> pdf (dvipdfmx)
```

## 発表者ノートの出し方

各フレーム直後の `\note{...}` が発表原稿（合計の目安 約7分）です。既定では
スライドのみが出力されます。ノートを出力するには、プリアンブル末尾にある
次の行のコメントを外してから再コンパイルしてください。

```tex
% ノートページをスライドの後ろに挿入
\setbeameroption{show notes}

% 発表者ビュー（左：スライド／右：ノート）
\setbeameroption{show notes on second screen=right}
```

次の画像は、LaTeX 本文を変更せず、`figures/` 内の同名ファイルを置き換えて

- `full-history-overlay.pdf` / `.png` / `.jpg`
  - 7枚目：実測値と全期間参照による予測値の重ね描き
- `w_sweep_summary.png`
  - 8枚目：参照期間 W に対する MAE と1ステップ当たり計算時間
    （全期間の点を含む版・含まない版のどちらでも収まるようにしてあります）

7枚目の画像は PDF、PNG、JPG のいずれか1つで構いません。同じ名前の画像が複数ある場合は
PDF、PNG、JPG の順に使用されます。画像が見つからない場合も
`\safeincludegraphics` がプレースホルダを表示するため、コンパイルは停止しません。

4・7・8枚目の図は `width` と `height` の両方を指定（`keepaspectratio`）してあるので、
縦横比が変わってもフレームからはみ出しません。差し替え後は念のため、コンパイル時に
`Overfull \vbox` の警告が出ていないかを確認してください。6・9枚目は横長
（幅：高さがおおむね 2.5:1 以上）の画像を想定して幅を調整しています。
