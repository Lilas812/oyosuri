# XAUUSD × 平均練行足 × 相関付きランダムウォーク モデル 作成書

## Context（背景・目的）

XAUUSD（金/ドル）の価格時系列に対して、教科書『相関付きランダムウォーク
による時系列モデル（第5章）』のアルゴリズムを当てはめる。価格を ±1 ステッ
プ列へ離散化するために **平均練行足（Mean Renko / カスタム練行足）** を用
いる。平均練行足は「継続でも反転でも値幅 B だけ動けば 1 本新足が生成され
る」対称足である。

教科書 §5.1 の式 (5.1) は時間発展対称型 `A(p)` を採用しているが、本書では
これを **左方向継続確率 `q`、右方向継続確率 `p` を独立に持つ非対称コイン
行列** に一般化する。教科書の対称型は `q = p` の特別な場合として包含される。

本書は **数式のみ** で記述する。ユーザは自前実装と本書を照合して整合性を
検証する。実装言語は Python (pandas / numpy) を想定するが、本書中ではコー
ドは書かない。

---

## 1. 入力データと記号

- 入力：TradingView から取得した XAUUSD のローソク足列
  （Open, High, Low, Close, Time）。
- 値幅（ボックスサイズ）：`B > 0` （価格単位）。事前に固定する。
- 平均練行足の足列： `b_1, b_2, …, b_N`、ただし `b_i ∈ {+1, -1}`。
- ランダムウォーク列：

  ```
  x_0 = 0,
  x_n = x_{n-1} + b_n     (n = 1, 2, …, N)
  ```

  `x_n` は **ボックス単位の整数**。
- 時刻 `n` までの観測時系列：`D_n = { x_0, x_1, …, x_n }`。

---

## 2. 平均練行足の生成規則

クラシック練行足と異なり、反転にも値幅 1 本分しか必要としない。

足 `b_i` の **始値** を `o_i` とおき、初回は `o_1 := P_0`（時系列開始時の
基準価格）とする。逐次到来する価格 `P_t` に対し、

- もし `P_t ≥ o_i + B` ならば、新足 `b_i = +1`、`o_{i+1} := o_i + B`。
- もし `P_t ≤ o_i − B` ならば、新足 `b_i = -1`、`o_{i+1} := o_i − B`。
- それ以外なら足は生成しない。

複数ボックス分一気に動いた場合（`|P_t − o_i| ≥ kB`、`k ≥ 2`）は、同一方向
へ `k` 本まとめて生成する：

```
b_i, b_{i+1}, …, b_{i+k-1}  全て同符号、
o_{i+k} = o_i ± kB
```

> 補足：B の決定法（ATR の何倍、固定 pip 値、等）は実装側の自由。本書では
> B は外部から与えられた定数とする。

## 3. 相関付きランダムウォーク（一般化2パラメータ型）

教科書 §5.1 の `A(p)` を **2 パラメータ `(p, q)`** に一般化する。

### 3.1 コイン行列と初期状態

意味付け：

- 左向きでそのまま左に進む確率 ＝ `q`
- 左向きで右に反転する確率   ＝ `1 − q`
- 右向きでそのまま右に進む確率 ＝ `p`
- 右向きで左に反転する確率   ＝ `1 − p`

これを 1 つのコイン行列にまとめる：

```
A(p, q) = ⎡  q    1−q ⎤        φ(α) = ⎡  α  ⎤,
          ⎣ 1−p    p  ⎦                ⎣ 1−α ⎦

0 ≤ p ≤ 1,   0 ≤ q ≤ 1,   0 ≤ α ≤ 1.
```

各列の和は `q + (1−q) = 1`, `(1−p) + p = 1` となり、教科書 §5.1 の制約
（`a+c = b+d = 1`）を満たす。`q = p` とおけば教科書の対称型 `A(p)` に
帰着する。

`A(p, q) = P(p, q) + Q(p, q)` と上下行に分解：

```
P(p, q) = ⎡  q    1−q ⎤,     Q(p, q) = ⎡  0    0  ⎤.
          ⎣  0     0  ⎦                ⎣ 1−p    p  ⎦
```

`P` は左移動、`Q` は右移動に対応する（教科書 §5.1 と同様、上行は次状態が
左向き、下行は次状態が右向きという解釈）。

### 3.2 経路和 Ξ̃ と確率分布 μ

時刻 `n` で左 `l` 回・右 `m` 回（`n = l + m`）動いた全パスの和：

```
Ξ̃_n(l, m) = Σ_{(ε_1,…,ε_n)∈{L,R}^n,  #L=l, #R=m}  X_{ε_n} ⋯ X_{ε_2} X_{ε_1}
```

ここで `X_L = P(p, q)`, `X_R = Q(p, q)`（右から積む）。

時刻 `n`、位置 `x = −l + m` における存在確率：

```
μ_n(x) = P(S̃_n = x) = ‖ Ξ̃_n(l, m) φ ‖_1.
```

`‖·‖_1` はベクトルの L1 ノルム（成分の絶対値和）。

### 3.3 時刻 n、位置 x における 2 成分確率ベクトル

```
Ψ_n(x) = ⎡ Ψ_n^L(x) ⎤,
         ⎣ Ψ_n^R(x) ⎦
μ_n(x) = ‖Ψ_n(x)‖_1 = |Ψ_n^L(x)| + |Ψ_n^R(x)|.
```

実装上は `Ψ_n(x)` を漸化式

```
Ψ_{n+1}(x) = P(p, q) Ψ_n(x+1) + Q(p, q) Ψ_n(x−1),
Ψ_0(0) = φ(α),    Ψ_0(x) = 0  (x ≠ 0)
```

で計算してよい（教科書 第2章の同値表現を 2 パラメータに拡張）。

### 3.4 既知の初期値（一般化版）

```
μ_0(0) = 1,
μ_1(−1) = ‖P(p, q) φ(α)‖_1 = q α + (1 − p)(1 − α),     … (5.3')
μ_1( 1) = ‖Q(p, q) φ(α)‖_1 = (1 − q) α + p (1 − α),     … (5.4')
μ_1(−1) + μ_1( 1) = α [q + (1−q)] + (1−α)[(1−p) + p] = 1.   … (5.5')
```

`q = p` とおくと教科書 §5.1 の (5.3), (5.4), (5.5) に一致する。

## 4. 評価関数 V_n（一般化版）

教科書 §5.1 で定義される時間依存評価関数を `(p, q, α)` の関数に拡張：

```
                   n     t
V_n(p, q, α) =   Σ     Σ      (x − x_t)^2 · μ_t(x;  p, q, α).
                 t=0  x=−t
```

- `x_t` は §1 で構成した **観測値**（ボックス単位整数）。
- `μ_t(x; p, q, α)` は §3 で計算した **モデル確率**。
- `V_n` は `(p, q, α) ∈ [0, 1]^3` 上の連続関数となる。

`n = 1` の具体形（検算用、`(5.3')` `(5.4')` `(5.5')` から導出）：

```
V_1(p, q, α) = (x_1 + 1)^2 · μ_1(−1) + (x_1 − 1)^2 · μ_1(1)
             = x_1^2  +  2 [μ_1(−1) − μ_1(1)] x_1  +  1
             = x_1^2  +  2 [α (2q − 1) + (1 − α)(1 − 2p)] x_1  +  1.    … (5.6')
```

各偏微分：

```
∂V_1/∂p  = − 4 (1 − α) x_1.            … (5.7'-p)
∂V_1/∂q  =   4 α x_1.                  … (5.7'-q)
∂V_1/∂α  =   4 (p + q − 1) x_1.        … (5.8')
```

`q = p` とおくと教科書 §5.2 の (5.6), (5.7), (5.8)
`V_1 = x_1^2 + 2(2p−1)(2α−1) x_1 + 1` に帰着する（検証用）。

## 5. 予測アルゴリズム（教科書 §5.1 ステップ 1〜3 を一般化）

時刻 `n` までのデータ `D_n = {x_0, x_1, …, x_n}` から `x_{n+1}` を予測する。

### ステップ 1．パラメータ最小化

`V_n(p, q, α)` を `[0, 1]^3` 上で最小にする全ての組

```
(p_n*, q_n*, α_n*) ∈ argmin_{(p, q, α) ∈ [0,1]^3} V_n(p, q, α)
```

を求める。複数解があり得る点に注意。

### ステップ 2．次時刻の予測値

- **(a) `V_n` が `(p, q, α)` に依らず定数の場合**

  ```
  x_{n+1}* := x_n.
  ```

- **(b) `(p_n*, q_n*, α_n*)` が一意の場合**

  ```
  x_{n+1}* := E( S̃_{n+1} | p_n*, q_n*, α_n* ).
  ```

- **(c) 最小化候補が複数 `{(p^{(k)}, q^{(k)}, α^{(k)})}_{k=1..K}` ある場合**

  偏りがないように **相加平均** をとる：

  ```
                1   K
  x_{n+1}* := ───  Σ  E( S̃_{n+1} | p^{(k)}, q^{(k)}, α^{(k)} ).
                K  k=1
  ```

期待値は §3.3 の `Ψ_n` を用いて直接計算する：

```
E( S̃_{n+1} | p, q, α )
   = Σ_{x = −(n+1)}^{n+1}  x · μ_{n+1}(x; p, q, α)
   = Σ_{x = −(n+1)}^{n+1}  x · ‖ Ψ_{n+1}(x; p, q, α) ‖_1.
```

> 注：教科書 §2 の系 2.13 は対称型 `A(p)` 用の閉じた式 (2.20), (2.21)
> を与えているが、本書の一般化 `A(p, q)` ではこれらは直接適用できない。
> 実装では §3.3 の漸化式から数値的に計算する。`q = p` の特別な場合に
> 限り、教科書の系 2.13 と一致することを検算してよい。

### ステップ 3．繰り返し

`n = 0, 1, 2, …` についてステップ 1 とステップ 2 を繰り返し、予測列

```
{ x_1*, x_2*, x_3*, … }
```

を得る。

## 6. 初期挙動と検証ケース

### 6.1 n = 0（一般化版でも不変）

`D_0 = {x_0 = 0}`。任意の `(p, q, α)` で `V_0 = 0` なので定数。
ステップ 2 (a) より

```
x_1* = x_0 = 0.
```

### 6.2 n = 1（一般化版の解析）

`D_1 = {x_0 = 0, x_1}`。式 (5.6'), (5.7'-p), (5.7'-q), (5.8') より、
`x_1` の符号で場合分けする。`V_1` の `x_1` に係る係数は

```
2 [α (2q − 1) + (1 − α)(1 − 2p)] x_1
```

である。

- **`x_1 > 0` の場合**：係数を最小化するため `α(2q−1) + (1−α)(1−2p)`
  を最小化したい。`α ∈ [0,1]` に対し
  - `q` の最適：`∂/∂q = 4α x_1 ≥ 0` → `q* = 0`
  - `p` の最適：`∂/∂p = −4(1−α) x_1 ≤ 0` → `p* = 1`
  - これらを代入すると、`α(2·0 − 1) + (1 − α)(1 − 2·1) = −α − (1−α) = −1`
    で、`α` に依らず一定。
  - 従って最小値は `V_1 = x_1^2 − 2 x_1 + 1 = (x_1 − 1)^2` となり、
    最小化集合は `{ (p, q, α) | p = 1, q = 0, α ∈ [0, 1] }`。

- **`x_1 = 0` の場合**：`V_1 ≡ 1`（定数）。ステップ 2 (a) より
  `x_2* = x_1 = 0`。

- **`x_1 < 0` の場合**：対称的に
  - `p* = 0`, `q* = 1`, `α ∈ [0, 1]` 任意
  - `V_1 = (x_1 + 1)^2`

### 6.3 教科書（対称型 `q = p`）との照合

`q = p` を強制すると、本書の最適化結果は教科書 §5.2 の結果と一致する：

| ケース      | 教科書 `(p_1*, α_1*)`            | 本書一般化での対応             |
|-------------|----------------------------------|--------------------------------|
| `x_1 > 0`   | `(0, 1)` および `(1, 0)`         | `(p, q, α) = (1, 0, ∀α)` 系   |
| `x_1 = 0`   | `V_1` 定数                        | `V_1` 定数                    |
| `x_1 < 0`   | `(0, 0)` および `(1, 1)`         | `(p, q, α) = (0, 1, ∀α)` 系   |

> 補足：教科書の `(0, 1)`, `(1, 0)` 型の解は `q = p` 制約下での最適点で
> あり、本書の一般化（`p` と `q` を独立に最適化）ではより大きな最適集合
> となる。検証用に **対称制約 `q = p` を入れた版** を用意し、教科書 §5.2
> 表 5.1 / 表 5.2 と数値が一致することを確認するのが望ましい。

### 6.4 n = 2 の検証点（対称制約版）

`q = p` を強制して教科書 §5.2 末尾の 2 例を再現できることを確認する：

- `D_2 = {0, 1, 2}` ⇒ `(p_2*, α_2*) = (1, 0)`, `x_3* = 3`.
- `D_2 = {0, 1, 0}` ⇒ `(p_2*, α_2*) = (0, 1)`, `x_3* = 0` 系の値（教科書
  §5.2 表 5.2 参照）。

これらは教科書 §2 系 2.13 の閉じた式に依存するため、対称制約版でのみ
ユニットテストすればよい。一般化版（`p ≠ q` 許容）では §3.3 の `Ψ_n`
漸化式での数値計算結果を真値とする。

## 7. XAUUSD への適用フロー（数式表現）

```
Step A. ローソク足 {(O_t, H_t, L_t, C_t)}_{t=1..T} を時系列順に走査。
Step B. 値幅 B を決定。
Step C. §2 の規則で平均練行足列 {b_1, …, b_N} を生成。
Step D. x_0 := 0,  x_n := x_{n-1} + b_n  (n=1..N) で離散ランダムウォーク化。
Step E. 各 n = 0, 1, …, N−1 について
          §5 のステップ 1〜2 を適用し、x_{n+1}* を得る。
Step F. 予測列 {x_1*, x_2*, …, x_N*} と実測 {x_1, …, x_N} を比較。
```

評価指標（参考、本書では数式のみ定義し採用は実装者に委ねる）：

```
MAE  = (1/N) Σ_{n=1}^{N} | x_n − x_n* |,
RMSE = sqrt( (1/N) Σ_{n=1}^{N} (x_n − x_n*)^2 ),
HIT  = (1/(N−1)) Σ_{n=2}^{N} 1[ sign(x_n − x_{n-1}) = sign(x_n* − x_{n-1}) ].
```

## 8. Verification（自前実装との照合手順）

ユーザが自前実装を本書と照合する際に必ず満たすべきチェックポイント：

1. **初期確率の数値一致**
   - `μ_0(0) = 1`
   - 任意の `(p, q, α)` について `μ_1(−1) + μ_1(1) = 1`
   - `(p, q, α) = (0.3, 0.4, 0.7)` 等を代入して `(5.3')`, `(5.4')` の
     数値一致を確認。

2. **式 (5.6') との一致**
   `n = 1` で `V_1(p, q, α)` を解析式
   `x_1^2 + 2[α(2q−1) + (1−α)(1−2p)] x_1 + 1`
   とモデル計算値が小数点以下 10 桁程度で一致すること。

3. **対称制約 `q = p` 下での教科書再現**
   - `q = p` を強制した場合に式 (5.6') が教科書の (5.6)
     `x_1^2 + 2(2p−1)(2α−1) x_1 + 1` と一致すること。
   - §6.4 の `D_2 = {0,1,2}` と `D_2 = {0,1,0}` で教科書 §5.2 表 5.2
     の予測値を再現すること。

4. **平均練行足の対称性**
   同一の価格列を時系列方向に与えたとき、上昇 1 ボックスと下降 1 ボックス
   に必要な価格変化量が等しいこと（クラシック練行足にならない）。

5. **`(p*, q*, α*)` 複数解時の平均化**
   `argmin` が 2 個以上得られる場合、必ず `E(S̃_{n+1})` を相加平均して
   `x_{n+1}*` を決定していること（最小値そのものではなく予測値の平均）。

6. **`V_n ≡ const` 判定**
   実数比較は許容誤差 ε（例：`1e−12`）付きで判定し、定数なら
   `x_{n+1}* = x_n` を返すこと。

7. **左右反転対称性**
   入力 `{x_n}` を符号反転（`x'_n := −x_n`）して同じ実装に通したとき、
   出力 `x'_{n+1}*` が `−x_{n+1}*` に等しいこと。これは `(p, q, α)` を
   `(q, p, 1−α)` に置換する変換に対応する。

## 10. 参考（教科書対応箇所と一般化の差分）

- §5.1 時系列モデル：教科書の `A(p)`（式 (5.1)）を本書では
  `A(p, q) = [[q, 1−q], [1−p, p]]` に拡張。
- §5.1 評価関数：`V_n` の定義は同じだが、引数が `(p, α) → (p, q, α)`。
- §5.1 予測アルゴリズム：ステップ 1〜3 の構造は同じ、最適化空間が
  `[0, 1]^2 → [0, 1]^3`。
- §5.2 具体例：式 (5.6)〜(5.13)、表 5.1〜5.3 は **対称制約 `q = p` の
  下でのみ** 直接適用可能。
- §2 系 2.13：`E(S̃_n)` の閉じた形（式 (2.20), (2.21) 等）は対称型
  限定のため、一般 `(p, q)` では §3.3 の漸化式から数値計算する。
